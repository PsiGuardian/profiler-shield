# Contribuții

[Cuprinsul documentației](README.md)

Lucrați într-o aplicație Symfony de test izolată. Păstrați disponibilitatea și refuzul diagnosticelor neautorizate. Testați cereri anonime, sesiuni revocate, program și stocare indisponibilă pe versiunile afectate. Folosiți chei stabile, escapare și traduceri complete. Fără secrete în teste, capturi sau Git; fără rețea obligatorie. Descrieți efectele și validarea.
```bash
composer install
composer test
php tests/translation_audit.php --strict
php tests/documentation_audit.php
node tests/password_model.js
vendor/bin/phpunit -c phpunit.xml.dist
```
