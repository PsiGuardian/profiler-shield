# अनुवाद

[दस्तावेज़ सूची](README.md)

पोर्टल में 28 क्षेत्रीय विकल्प और 25 कैटलॉग हैं; चार अंग्रेज़ी विकल्प एक कैटलॉग साझा करते हैं। स्थिर पाठ अनुवाद के बाद सुरक्षित एस्केप होता है। उपयोगकर्ता नाम, अनुकूलित संदेश और डेटा का अनुवाद नहीं होता। किसी दूरस्थ सेवा को पाठ नहीं भेजा जाता। ऑडिट कुंजियाँ, पैरामीटर, UTF-8, कमांड और लिंक जाँचता है; HTTP परीक्षण हर विकल्प के दृश्य देखते हैं।
