## सार्वजनिक त्रुटि पृष्ठ

ऐप के पृष्ठ बनाए रखें या आगंतुकों को तटस्थ HTML दिखाएँ। वास्तविक HTTP स्थिति कोड अपरिवर्तित रहते हैं।

माता-पिता के मुकाबले Symfony त्रुटियों को प्रदर्शित करना. जनरल मोड अनुकूलित पाठ को अनदेखा करता है. केवल कस्टम मोड में आगंतुकों के संदेश का उपयोग किया जाता है. सार्वजनिक संदर्भ अनुपस्थित, यादृच्छिक या निश्चित हो सकता है; यह संदेश से स्वतंत्र है. HTTP स्थिति कोड अपरिवर्तनीय रहते हैं।

अनुप्रयोग पृष्ठ: मौजूदा साइट को बनाए रखता है 404 अनुच्छेदों का उपयोग करें; अपवाद 404 जब उपलब्ध हो तो टेम्पलेट, अन्यथा एक तटस्थ पृष्ठ. साइड: मानक संदेश. अनुकूलित: आपके पाठ का उपयोग करें.

अनाम 500 अपवादों को तटस्थ पृष्ठ मिलता है। विवरण के लिए अधिकृत Guardian पहचान और GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=1 चाहिए। अनुपस्थित या खराब Twig टेम्पलेट तटस्थ प्रदर्शन देते हैं; अपने त्रुटि नियंत्रकों हेतु अलग एकीकरण चाहिए। JSON और सफल व्यावसायिक पृष्ठ नहीं बदलते।

| error_mode | सेटिंग्स |
|---|---|
| native | अनुप्रयोग पृष्ठ: मौजूदा साइट को बनाए रखता है 404 अनुच्छेदों का उपयोग करें; अपवाद 404 जब उपलब्ध हो तो टेम्पलेट, अन्यथा एक तटस्थ पृष्ठ. साइड: मानक संदेश. अनुकूलित: आपके पाठ का उपयोग करें. |
| generic | HTML 400–599 → ऐप के पृष्ठ बनाए रखें या आगंतुकों को तटस्थ HTML दिखाएँ। वास्तविक HTTP स्थिति कोड अपरिवर्तित रहते हैं। |
| custom | केवल अनुकूलित तटस्थ संदेश के लिए उपलब्ध। मोड बदलने पर पाठ सुरक्षित रहता है। (≤360 Unicode) |
| error_reference | none / random / custom |
| error_reference_text | केवल एक अनुकूलित स्थैतिक संदर्भ के साथ उपलब्ध है। |
| error_custom_text | केवल अनुकूलित तटस्थ संदेश के लिए उपलब्ध। मोड बदलने पर पाठ सुरक्षित रहता है। |

## दिखाया गया संदर्भ

अलग संदेश या स्थिर संदर्भ वास्तविक त्रुटि प्रकट कर सकते हैं। HTTP कोड गलत नहीं दिखाने चाहिए।

संदर्भ के लिए लागू होता है Guardian's तटस्थ पृष्ठ: यादृच्छिक रूप से एक नया कोड उत्पन्न करता है, न कि एक यादृश्य संदेश. यह एक लॉग संबंध पहचानकर्ता नहीं है.

सहेजने से पहले विकल्प सर्वर पर जाँचे जाते हैं।

```text
templates/bundles/TwigBundle/Exception/error404.html.twig
templates/bundles/TwigBundle/Exception/error.html.twig
GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=1

HTTP 400 / 403 / 404 / 429 / 500 / 503
application/json → application/json; application/problem+json → application/problem+json
HTML 2xx → HTML 2xx
HTTP 404 → HTTP 404; HTTP 500 → HTTP 500
```

## नेटवर्क और तैनाती

IP अनुमति सूची स्वीकार करता है IPv4, IPv6 और CIDR नेटवर्क - चेक Symfony इसे सक्षम करने से पहले भरोसेमंद प्रॉक्सी कॉन्फ़िगरेशन। HTTPS सुरक्षित कुकीज़ के लिए Guardian वे वेब सर्वर या डेटाबेस की मरम्मत नहीं करते हैं।

पहचान, भूमिका, सत्र, नेटवर्क, समय-सारणी, JIT या लॉक जाँचे न जा सकें तो निदान रोकें। समाप्ति ब्राउज़र तय नहीं करता। संग्रह और देखना अलग हैं। उपकरण याद रखना प्रमाणीकरण नहीं है। आपात पहुँच हेतु पहचान, खर्च किया कोड और टिकाऊ ऑडिट चाहिए; गंभीर ऑडिट विफलता खोलना रोकती है। अमान्य कॉन्फ़िगरेशन आंशिक रूप से लागू न करें। वैकल्पिक नियंत्रण दूरस्थ सेवा अनिवार्य नहीं करते।
