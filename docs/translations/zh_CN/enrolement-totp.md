# 双因素身份验证

[文档目录](README.md)


## 双因素身份验证

每个人都有自己的登记 TOTP 秘密和确认一个代码。

每个人都有自己的登记 TOTP 秘密和确认一个代码。 MFA 区块不登记的帐户访问个人资料。 选择手动设置并输入显示的密钥。使用 SHA-1、六位数字和 30 秒周期。

## 1. 确认您的身份

输入您登录 Guardian 时使用的密码。此设置过程只需输入一次。

## 2. 在身份验证应用中输入密钥

选择手动设置并输入显示的密钥。使用 SHA-1、六位数字和 30 秒周期。

## 3. 确认六位验证码

输入验证器显示的验证码，无需再次输入密码。

## 隐私：不要输入网站 URL

如果验证器要求名称或网站，只填写“ΩGuardian”或中性别名。不要输入 Symfony 实例的 URL。

请保密：它能够生成 TOTP 验证码。不要分享或截屏。

临时秘密在 10 分钟或 5 次错误代码后失效，此时重新设置。错误代码保留表单，不再次索要密码。确认计数器被消费以防重放。

## 恢复和验证

移除 username 的 TOTP 秘密和计数器，撤销会话并记录操作。重新注册验证器；全局 MFA 要求仍有效，可能继续阻止分析器访问。


```bash
php bin/console guardian:mfa:reset admin --env=dev
```
