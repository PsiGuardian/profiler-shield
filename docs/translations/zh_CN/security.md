# 安全政策

[文档目录](README.md)

请私下联系 bundle-sec@omegaguardian.fr 协商加密渠道报告漏洞。首封消息不要包含秘密、活动令牌或私有 URL。提供 Guardian、Symfony、PHP 版本、影响、前提和最小复现。维护者确认、调查、私下修复、测试，并协调公告和补丁。

切勿通过电子邮件发送密码、TOTP 密钥、加密密钥或诊断 URL。

一起备份保管库和密钥，并测试恢复。丢失密钥不会自动重新生成。卸载后仅在私有环境检查分析器。生产环境：APP_DEBUG=0，禁用 WebProfilerBundle 和收集。受侵主机上的本地审计链不能证明完整性。
