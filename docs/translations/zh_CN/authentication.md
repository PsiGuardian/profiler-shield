## 账户和第一次登录

欢迎来到Guardian. 您的初始密码是暂时的. 选择一个新的秘密:面板和诊断保持锁定,直到您这样做。

Guardian 帐户与网站帐户分开. 初始帐户和新帐户必须在继续之前更改密码. 安全角色视图允许信息没有个人资料访问。

准备私有路径、密钥、保管库、Symfony 文件，并在没有活动管理员时创建管理员。保留现有账户。拒绝生产环境。直接运行后应清除缓存并执行检查。


```bash
php bin/console guardian:access --env=dev
```


| 保存密码要求 | 最小长度(Unicode 人物) |
|---|---|
| initial-admin-credentials.txt | 0600; random_int; &gt;=32 |
| password_policy[min_length] | 8–64; 15 |
| input | Unicode; ≤512 UTF-8 B |
| Argon2id | PHP + Argon2id → Argon2id |
| bcrypt | PHP − Argon2id → bcrypt; ≤72 UTF-8 B |

## 密码政策

这些规则适用于密码创建和更改,在网页上和 CLI他们不透露或检查现有密码。

初始值: 15 字符. 使用一个独特的密码或密码管理员. 所需的字符类别不保证一个不可预测的密钥。

在这个服务器上, Guardian 自动使用 Argon2id 新密码,保持其 PHP 支持可用:申请限制 512 UTF-8 比特。

这个 PHP 服务器不提供 Argon2id. Guardian 因此,使用 bcrypt 拒绝超越密码 72 UTF-8 请您的系统管理员允许 Argon2id 支持在 PHP.

此选项立即取消现有会议,包括您的帐户必须在设置卫报或打开诊断之前更改密码。

通过符合当前策略的隐藏输入更改现有 username 账户的密码，撤销所有会话并记录操作。不要将密码作为参数。

## 进步的锁

每个阶段都定义了一个失败限制,计算窗口,锁期和重复窗口。 10 失败引发A 10重复的故障可以引发下一个阶段. 检查覆盖了帐户和网络起源,包括管理员确认。

加密计数器分别针对规范化账户和来源；不保存原始 IP。哈希前进行原子预约，120 秒后过期。放弃的预约计为失败；迟到结果不能创建会话。无效 CSRF 不预约。成功登录清除账户失败，但保留重复和来源历史。达到 10000 活动记录时拒绝新身份，而不挤出锁定记录。

步骤按顺序运行. 在锁定后,重复窗口内的新故障使用下一个阶段. 在此窗口之外,第一个阶段再次适用。 8 下一篇:地方康复: guardian:login:unlock --all.

| 阶段 | 保存密码要求 |
|---|---|
| 锁之前的失败 | 1–100 |
| 点击(分钟) | 1–10080 |
| 计算窗口(分钟) | 1–1440 |
| 打开后重复窗口(分钟) | 1–10080 |
| 阶段 | 1–8; block[n+1] ≥ block[n] |
| 初始值 | 10 / 10 / 30 / 30 |
| 5 → 10 min; 5 → 2 h | 5 / 10 / 30 / 30 → 5 / 120 / 30 / 30 |
| HTTP | 429; Retry-After |

## 全面搜索成本实验室

平等地比较固定长度的随机秘密,而无需输入真实密码。 猜测率和硬件价格是可调整的假设. 没有登录尝试发送。

使用互斥 ASCII 类别和 BigInt。容斥原理计算精确搜索空间；缺少类别或长度不足时为零。无放回平均排名为 (N+1)/2。预期锁定时间考虑阈值与重复的最后阶段。速率不符合窗口时禁用估算。离线费用等于小时数乘以假设的每小时成本。

有了固定字母,要求一个类别减少了符合秘密的数量. 扩展字母是不同的操作。

这个模型不测量人类选择的密码的强度,它排除词典、重复使用、泄漏和目标策略,网页锁定不会保护被盗的黑客。 CPU 测量: guardian:password:benchmark.

大数字写成完整,有数字组合和没有E分数。时间和成本是圆形的. 使用相同假设比较相同序列。

| 可用的模拟字母 | 可能符合的秘密 |
|---|---|
| ASCII 下案例 | 26 |
| ASCII 顶部 | 26 |
| ASCII 数字 | 10 |
| ASCII 排除空间的象征 | 32 |
| 接收的在线利率(客人/s) | 1 / s |
| 假设非线利率(hashes/s) | 10000 / s |
| 固定硬件成本(每小时) | 2 € / h |

```bash
php bin/console guardian:password:benchmark --iterations=3 --env=dev
```

## 恢复和验证

一起备份保管库和密钥，并测试恢复。丢失密钥不会自动重新生成。卸载后仅在私有环境检查分析器。生产环境：APP_DEBUG=0，禁用 WebProfilerBundle 和收集。受侵主机上的本地审计链不能证明完整性。

重置 username 的账户计数器。--ip 地址 同时清除该 IPv4/IPv6 来源的计数器，否则网络锁定可能仍存在。--all 清除全部计数器。账户、密码和会话不变；操作会记录。
