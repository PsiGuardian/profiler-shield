# Συνεισφορά

[Περιεχόμενα τεκμηρίωσης](README.md)

Εργαστείτε σε απομονωμένη εφαρμογή δοκιμών Symfony. Διατηρήστε διαθεσιμότητα και απόρριψη μη εξουσιοδοτημένων διαγνωστικών. Ελέγξτε ανώνυμα αιτήματα, ανακληθείσες συνεδρίες, ωράρια και βλάβες αποθήκευσης στις σχετικές εκδόσεις. Σταθερά κλειδιά, ασφαλής διαφυγή και πλήρεις μεταφράσεις. Χωρίς μυστικά σε δοκιμές, εικόνες ή Git· χωρίς υποχρεωτικό δίκτυο. Περιγράψτε επιπτώσεις και ελέγχους.
```bash
composer install
composer test
php tests/translation_audit.php --strict
php tests/documentation_audit.php
node tests/password_model.js
vendor/bin/phpunit -c phpunit.xml.dist
```
