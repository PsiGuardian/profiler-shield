## Εμφανιζόμενη αναφορά

Διαφορετικά μηνύματα ή στατικές αναφορές μπορεί να αποκαλύψουν το πραγματικό σφάλμα. Οι κωδικοί HTTP δεν πρέπει να παραποιούνται.

Η αναφορά ισχύει για Guardian's ουδέτερες σελίδες: τυχαία παράγει έναν νέο κώδικα, όχι ένα τυχαίο μήνυμα.

Οι επιλογές ελέγχονται στον διακομιστή πριν αποθηκευτούν.

```text
templates/bundles/TwigBundle/Exception/error404.html.twig
templates/bundles/TwigBundle/Exception/error.html.twig
GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=1

HTTP 400 / 403 / 404 / 429 / 500 / 503
application/json → application/json; application/problem+json → application/problem+json
HTML 2xx → HTML 2xx
HTTP 404 → HTTP 404; HTTP 500 → HTTP 500
```
