# Μεταφράσεις

[Περιεχόμενα τεκμηρίωσης](README.md)

Η πύλη προσφέρει 28 περιφερειακές παραλλαγές και 25 καταλόγους· οι τέσσερις αγγλικές μοιράζονται κατάλογο. Το στατικό κείμενο μεταφράζεται και διαφεύγει με ασφάλεια. Ονόματα, προσαρμοσμένα μηνύματα και δεδομένα χρηστών δεν μεταφράζονται. Καμία εξωτερική υπηρεσία δεν λαμβάνει κείμενα. Το audit ελέγχει κλειδιά, παραμέτρους, UTF-8, εντολές και συνδέσμους· τα HTTP τεστ επισκέπτονται τις προβολές κάθε γλώσσας.
```bash
php tests/translation_audit.php --strict
php tests/documentation_audit.php
composer test
```
