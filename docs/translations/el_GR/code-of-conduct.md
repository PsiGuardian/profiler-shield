# Κώδικας συμπεριφοράς

[Περιεχόμενα τεκμηρίωσης](README.md)

Συζητήστε με σεβασμό, ακρίβεια και γεγονότα. Απαγορεύονται παρενόχληση, προσωπικές επιθέσεις, ιδιωτικά δεδομένα και μη συντονισμένες αποκαλύψεις ευπαθειών. Οι υπεύθυνοι μπορούν να συντονίζουν και να περιορίζουν λογαριασμούς. Ευαίσθητες αναφορές ακολουθούν την πολιτική ασφαλείας.
