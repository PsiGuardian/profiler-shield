# Πολιτική ασφαλείας

[Περιεχόμενα τεκμηρίωσης](README.md)

Αναφέρετε ιδιωτικά ευπάθειες στο bundle-sec@omegaguardian.fr για κρυπτογραφημένο κανάλι. Χωρίς μυστικά, ενεργά tokens ή ιδιωτικά URL στο πρώτο μήνυμα. Δώστε εκδόσεις Guardian, Symfony και PHP, επίπτωση, προϋποθέσεις και ελάχιστη αναπαραγωγή. Οι υπεύθυνοι επιβεβαιώνουν, ερευνούν, διορθώνουν ιδιωτικά, δοκιμάζουν και συντονίζουν ανακοίνωση και διόρθωση.

Μην αποστέλλετε ποτέ με email κωδικούς πρόσβασης, μυστικά TOTP, κλειδιά κρυπτογράφησης ή URL διάγνωσης.

Αντιγράψτε θησαυροφυλάκιο και κλειδί μαζί και δοκιμάστε επαναφορά. Χαμένα κλειδιά δεν αναδημιουργούνται αυτόματα. Μετά την αφαίρεση ελέγξτε τον profiler μόνο ιδιωτικά. Παραγωγή: APP_DEBUG=0, WebProfilerBundle και συλλογή ανενεργά. Τοπική αλυσίδα δεν αποδεικνύει ακεραιότητα παραβιασμένου host.
