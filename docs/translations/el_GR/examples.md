# Παραδείγματα διεπαφής

[Περιεχόμενα τεκμηρίωσης](README.md)

Δημιουργεί προσωρινές προβολές HTML με συνθετικούς λογαριασμούς και κατεστραμμένες δοκιμαστικές συνεδρίες. Δεν είναι συνδεδεμένοι πίνακες· μην δημοσιεύετε ως υπηρεσία διαχείρισης. Οι προεπισκοπήσεις εξαιρούνται από τα διανεμόμενα αρχεία.
```bash
GUARDIAN_EXPORT_PREVIEW=1 php tests/flow_smoke.php
```
