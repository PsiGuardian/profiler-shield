## Πρόσθετες προστασίες

Οι έλεγχοι ομαδοποιούνται με τις ρυθμίσεις τους. Οι ανενεργές επιλογές εμφανίζονται γκρι και οι τιμές διατηρούνται.

Guardian ελέγχει το προφίλ και τη γραμμή εργαλείων αποσύνδεσης. απαιτείται ένας εξουσιοδοτημένος διαχειριστής ή λογαριασμός προγραμματιστή. MFAκαι τα χρονοδιαγράμματα, JITΟι περιορισμοί δικτύου και η κλειδαριά ενδέχεται ακόμα να αρνηθούν την πρόσβαση. ο τρόπος κλοπής κρύβει σημεία εισόδου. δεν αντικαθιστά αυτούς τους ελέγχους.


```text
POST ∧ CSRF ∧ role=admin ∧ password
```

Επιτρέπεται η προγραμματισμός, οι επιλεγμένες ημέρες, μια ενσωματωμένη ώρα έναρξης και μια αποκλειστική ώρα λήξης. Η αποθηκευμένη ζώνη χρόνου καθορίζει τις τοπικές ώρες. Τα διαστήματα της νύχτας δεν είναι αποδεκτά. Το να κρύβετε την πύλη έξω από τις ώρες εμποδίζει την πρόσβαση εξ αποστάσεως έκτακτης ανάγκης. Κρατήστε διαθέσιμες τοπικές εντολές ανάκαμψης.

Το Idle timeout, η απόλυτη διάρκεια ζωής και η μνήμη της συσκευής εξυπηρετούν διαφορετικούς σκοπούς.Το να θυμάσαι μια συσκευή δεν υπερβαίνει τα χρονοδιαγράμματα ή JITΗ ανάκληση τερματίζει τις σχετικές συνεδρίες στον διακομιστή. Χρησιμοποιήστε μεμονωμένους λογαριασμούς για να αναθέσετε ενέργειες στο ημερολόγιο.

JIT απαιτεί την ενεργοποίηση ενός προσωρινού παράθυρου από μια εξουσιοδοτημένη συνεδρία. Η πρόσβαση έκτακτης ανάγκης, όταν είναι ενεργοποιημένη, απαιτεί έναν κωδικό πρόσβασης, έναν κώδικα χρήσης και έναν λόγο. Δεν ξεπερνά το παγκόσμιο κλείσιμο. Οι τοπικές εντολές παραμένουν απαραίτητες εάν η πύλη δεν είναι προσβάσιμη.

Το IP επιτρέπει την αποδοχή IPv4, IPv6 και CIDR Δίκτυο - Ελέγξτε Symfony εμπιστευτική διαμόρφωση proxy πριν την ενεργοποιήσετε. HTTPS Για ασφαλή cookies. Guardian Δεν επισκευάζει εκτεθειμένους web servers ή βάσεις δεδομένων.

Το επίπεδο και η διατήρηση καθορίζουν τα διαθέσιμα γεγονότα, μέχρι 5000 Εισαγωγές. Φίλτρο με τύπο και λογαριασμό πριν από την αλλαγή σελίδων. Οι προειδοποιήσεις αποσυνδέονται. ρυθμίστε τη μεταφορά και την παράδοση τους. Μια τοπική αλυσίδα hash δεν εγγυάται ακεραιότητα σε έναν καταπιεσμένο host.

Καθορίστε το ελάχιστο μήκος και τις απαιτούμενες κατηγορίες σε συνδέσεις και κωδικούς πρόσβασης. Τα σήματα δημιουργίας λογαριασμού περιγράφουν την αποθηκευμένη πολιτική. Οι αλλαγές ισχύουν για νέους κωδούς πρόσβαση. επιλέξτε υποχρεωτική ανανέωση για τους υπάρχοντες λογαριασμούς. Guardian Επιλογές Argon2id Όταν PHP Το προσφέρει, αλλιώς bcrypt.

Φιλτράρετε όλα τα γεγονότα που διατηρούνται ανά τύπο και λογαριασμό.Οι τελευταίες εκδηλώσεις εμφανίζονται πρώτα, στις σελίδες των 50Το Scrolling δεν φορτώνει την επόμενη σελίδα.

## Περιβάλλον


```dotenv
GUARDIAN_LOGIN_PATH=/internal/<random-48-hex>
GUARDIAN_ENCRYPTION_KEY=<64-hex>
GUARDIAN_STORAGE_DIR=<private-directory>
GUARDIAN_COLLECTION_BRIDGE=0
GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=0
GUARDIAN_SHOW_PHP_VERSION=0
```


Ο proxy χειρίζεται TLS, κανονικοποίηση και ογκομετρική προστασία. Η πύλη ελέγχει πριν τον router· οι επιχειρησιακές διαδρομές δεν διαβάζουν λογαριασμούς ή συνεδρίες. Οι ταυτότητες Guardian είναι χωριστές από το Symfony. Αντιγράψτε θησαυροφυλάκιο και κλειδί μαζί εκτός δημόσιου καταλόγου. Παραβιασμένο PHP ή σύστημα μπορεί να εκθέσει και τα δύο. Η αποθήκευση είναι για έναν host. Σφάλματα εκκίνησης, cache ή proxy μπορούν να επηρεάσουν όλη την εφαρμογή.

Αντιγράψτε θησαυροφυλάκιο και κλειδί μαζί και δοκιμάστε επαναφορά. Χαμένα κλειδιά δεν αναδημιουργούνται αυτόματα. Μετά την αφαίρεση ελέγξτε τον profiler μόνο ιδιωτικά. Παραγωγή: APP_DEBUG=0, WebProfilerBundle και συλλογή ανενεργά. Τοπική αλυσίδα δεν αποδεικνύει ακεραιότητα παραβιασμένου host.

## Αποκατάσταση και επαλήθευση

Αδειάζει τη λίστα IP και απενεργοποιεί ωράριο, JIT και απομακρυσμένη έκτακτη πρόσβαση. Έλεγχος ταυτότητας, MFA, καθολικό κλείδωμα και αποκλεισμοί σύνδεσης παραμένουν. Ρυθμίστε ξανά τους επιθυμητούς περιορισμούς.

on κλείνει τα διαγνωστικά και αφαιρεί όλες τις συνεδρίες· οι επιχειρησιακές σελίδες λειτουργούν. off αίρει μόνο το καθολικό κλείδωμα: απαιτείται νέα σύνδεση και ισχύουν οι άλλες πολιτικές.


```bash
php bin/console guardian:policy:reset --env=dev
php bin/console guardian:lockdown on --env=dev
php bin/console guardian:doctor --env=dev
```
