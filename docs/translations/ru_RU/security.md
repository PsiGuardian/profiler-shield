# Политика безопасности

[Содержание документации](README.md)

Сообщайте о уязвимостях приватно на bundle-sec@omegaguardian.fr для согласования шифрованного канала. Без секретов, активных токенов и закрытых URL в первом письме. Укажите версии Guardian, Symfony и PHP, влияние, условия и минимальное воспроизведение. Разработчики подтверждают, исследуют, исправляют приватно, тестируют и координируют уведомление и исправление.

Никогда не отправляйте по почте пароли, секреты TOTP, ключи шифрования или диагностические URL.

Копируйте хранилище и ключ вместе, проверяйте восстановление. Потерянные ключи автоматически не генерируются заново. После удаления проверяйте профайлер только приватно. Production: APP_DEBUG=0, WebProfilerBundle и сбор отключены. Локальная цепочка аудита не доказывает целостность захваченного хоста.
