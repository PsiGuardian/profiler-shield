# Переводы

[Содержание документации](README.md)

Портал предлагает 28 региональных вариантов и 25 каталогов; четыре английских варианта используют общий каталог. Статический текст переводится и экранируется. Имена, собственные сообщения и данные пользователей не переводятся. Удалённым сервисам тексты не передаются. Аудит проверяет ключи, параметры, UTF-8, команды и ссылки; HTTP-тесты обходят представления всех вариантов.
```bash
php tests/translation_audit.php --strict
php tests/documentation_audit.php
composer test
```
