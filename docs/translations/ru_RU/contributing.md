# Участие в разработке

[Содержание документации](README.md)

Работайте в изолированном тестовом Symfony-приложении. Сохраняйте доступность бизнеса и отказ в неразрешённой диагностике. Проверяйте анонимные запросы, отозванные сессии, расписание и ошибки хранилища на затронутых версиях. Используйте стабильные ключи, экранирование и полные переводы. Без секретов в тестах, снимках и Git; без обязательной сети. Опишите последствия и проверки.
```bash
composer install
composer test
php tests/translation_audit.php --strict
php tests/documentation_audit.php
node tests/password_model.js
vendor/bin/phpunit -c phpunit.xml.dist
```
