## Публичные ошибки страницы

Сохраняйте страницы приложения или показывайте нейтральный HTML. Реальные коды состояния HTTP не меняются.

Родительские моды позволяют Symfony Общий режим игнорирует персонализированный текст. Только персонализованный режим использует сообщение посетителя. Общественная ссылка может быть отсутствием, случайным или фиксированным; она независима от сообщения. HTTP Статус кодов остается неизменным.

Страницы приложения: сохранение существующего сайта 404 Ответы; исключения используют 404 шаблон, когда он доступен, в противном случае нейтральная страница. Нейтральное: стандартное сообщение.

Анонимные исключения 500 получают нейтральную страницу. Подробности требуют разрешённой идентичности Guardian и GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=1. Отсутствующий или неисправный Twig даёт нейтральный вывод; собственные контроллеры ошибок требуют интеграции. JSON и успешные бизнес-страницы не меняются.

| error_mode | Настройки |
|---|---|
| native | Страницы приложения: сохранение существующего сайта 404 Ответы; исключения используют 404 шаблон, когда он доступен, в противном случае нейтральная страница. Нейтральное: стандартное сообщение. |
| generic | HTML 400–599 → Сохраняйте страницы приложения или показывайте нейтральный HTML. Реальные коды состояния HTTP не меняются. |
| custom | Доступно только для собственного нейтрального сообщения. Текст сохраняется при смене режима. (≤360 Unicode) |
| error_reference | none / random / custom |
| error_reference_text | Доступно только с стандартной статической ссылкой. |
| error_custom_text | Доступно только для собственного нейтрального сообщения. Текст сохраняется при смене режима. |

## Отображаемая ссылка

Разные сообщения или статические ссылки могут раскрыть реальную ошибку. Нельзя подменять коды HTTP.

Реферат относится к GuardianНейтральные страницы: случайно генерирует новый код, а не случайное сообщение.

Данные проверяются на сервере перед сохранением.

```text
templates/bundles/TwigBundle/Exception/error404.html.twig
templates/bundles/TwigBundle/Exception/error.html.twig
GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=1

HTTP 400 / 403 / 404 / 429 / 500 / 503
application/json → application/json; application/problem+json → application/problem+json
HTML 2xx → HTML 2xx
HTTP 404 → HTTP 404; HTTP 500 → HTTP 500
```

## Сеть и развертывание

IP разрешительный список принимает IPv4, IPv6 и CIDR Сети - проверка Symfony Доверенная конфигурация прокси перед тем, как сделать это возможно. HTTPS Для безопасных куки. Guardian не ремонтирует выявленные веб-серверы или базы данных.

Отказывайте в диагностике, если нельзя проверить идентичность, роль, сессию, сеть, расписание, JIT или блокировку. Браузер не определяет истечение срока. Сбор и просмотр раздельны. Запоминание устройства не аутентифицирует. Экстренный доступ требует идентичности, использованного кода и долговечного аудита; критический сбой аудита запрещает открытие. Неверную конфигурацию нельзя применять частично. Опциональные меры не требуют удалённого сервиса.
