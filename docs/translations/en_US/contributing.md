# Contributing

[Documentation contents](README.md)

Work in an isolated Symfony test application. Preserve business availability and denial of unauthorized diagnostics. Test anonymous requests, revoked sessions, schedules and unavailable storage on affected versions. Use stable keys, escape text and complete translations. No secrets in tests, screenshots or Git; no mandatory network dependency. Describe effects and validation.
```bash
composer install
composer test
php tests/translation_audit.php --strict
php tests/documentation_audit.php
node tests/password_model.js
vendor/bin/phpunit -c phpunit.xml.dist
```
