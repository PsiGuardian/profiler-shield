# Sumbangan

[Kandungan dokumentasi](README.md)

Bekerja dalam aplikasi ujian Symfony terasing. Kekalkan perniagaan tersedia dan penolakan diagnostik tanpa izin. Uji permintaan tanpa identiti, sesi dibatalkan, jadual dan kegagalan storan pada versi berkaitan. Gunakan kunci stabil, escape dan terjemahan lengkap. Tiada rahsia dalam ujian, imej atau Git; tiada rangkaian wajib. Huraikan kesan dan pengesahan.
```bash
composer install
composer test
php tests/translation_audit.php --strict
php tests/documentation_audit.php
node tests/password_model.js
vendor/bin/phpunit -c phpunit.xml.dist
```
