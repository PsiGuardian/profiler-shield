# უსაფრთხოების პოლიტიკა

[დოკუმენტაციის სარჩევი](README.md)

დაუცველობა პირადად აცნობეთ bundle-sec@omegaguardian.fr-ს დაშიფრული არხის შესათანხმებლად. პირველ შეტყობინებაში არ გააგზავნოთ საიდუმლო, აქტიური ტოკენი ან პირადი URL. მიუთითეთ Guardian-ის, Symfony-ისა და PHP-ის ვერსიები, გავლენა, პირობები და მინიმალური გამეორება. პასუხისმგებლები ადასტურებენ მიღებას, იკვლევენ, პირადად ასწორებენ, ტესტავენ და ათანხმებენ შეტყობინებასა და შესწორებას.

არასოდეს გაგზავნოთ ელფოსტით პაროლები, TOTP საიდუმლოებები, დაშიფვრის გასაღებები ან დიაგნოსტიკური URL-ები.

საცავი და გასაღები ერთად შეინახეთ და აღდგენა გამოსცადეთ. დაკარგული გასაღები ავტომატურად არ იქმნება. წაშლის შემდეგ პროფაილერი მხოლოდ დახურულ გარემოში შეამოწმეთ. საწარმოო გარემო: APP_DEBUG=0, WebProfilerBundle და შეგროვება გამორთულია. აუდიტის ადგილობრივი ჯაჭვი გატეხილი ჰოსტის მთლიანობას ვერ ამტკიცებს.
