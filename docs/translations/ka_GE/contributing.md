# წვლილის შეტანა

[დოკუმენტაციის სარჩევი](README.md)

იმუშავეთ იზოლირებულ Symfony სატესტო აპლიკაციაში. შეინარჩუნეთ ბიზნესის ხელმისაწვდომობა და არაავტორიზებული დიაგნოსტიკის უარყოფა. შესაბამის ვერსიებზე გამოცადეთ ანონიმური მოთხოვნები, გაუქმებული სესიები, განრიგი და საცავის შეცდომები. გამოიყენეთ სტაბილური გასაღებები, უსაფრთხო კოდირება და სრული თარგმანები. არ ჩადოთ საიდუმლო ტესტებში, სურათებში ან Git-ში; არ მოითხოვოთ სავალდებულო ქსელი. აღწერეთ შედეგები და შემოწმება.
```bash
composer install
composer test
php tests/translation_audit.php --strict
php tests/documentation_audit.php
node tests/password_model.js
vendor/bin/phpunit -c phpunit.xml.dist
```
