# თარგმანები

[დოკუმენტაციის სარჩევი](README.md)

პორტალს აქვს 28 რეგიონული ვარიანტი და 25 კატალოგი; ოთხი ინგლისური ვარიანტი ერთ კატალოგს იყენებს. სტატიკური ტექსტი ითარგმნება და უსაფრთხოდ იკოდება. მომხმარებლის სახელები, მორგებული შეტყობინებები და მონაცემები არ ითარგმნება. ტექსტი გარე სერვისს არ ეგზავნება. აუდიტი ამოწმებს გასაღებებს, პარამეტრებს, UTF-8-ს, ბრძანებებსა და ბმულებს; HTTP ტესტები ყველა ვარიანტის გვერდს ამოწმებს.
