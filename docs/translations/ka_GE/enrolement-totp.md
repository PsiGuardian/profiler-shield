# ორფაქტორიანი ავთენტიფიკაცია

[დოკუმენტაციის სარჩევი](README.md)


## ორფაქტორიანი ავთენტიფიკაცია

თითოეული ადამიანი არეგისტრირებს საკუთარ TOTP საიდუმლოს და ადასტურებს კოდს.

თითოეული ადამიანი არეგისტრირებს საკუთარ TOTP საიდუმლოს და ადასტურებს კოდს. MFA-ის მოთხოვნა არარეგისტრირებულ ანგარიშებს პროფაილერზე წვდომას უზღუდავს. მთელი გუნდისთვის ჩართვამდე დაგეგმეთ აღდგენა. აირჩიეთ ხელით დაყენება და შეიყვანეთ ნაჩვენები გასაღები. გამოიყენეთ SHA-1, ექვსი ციფრი და 30-წამიანი პერიოდი.

## 1. დაადასტურეთ ვინაობა

შეიყვანეთ იგივე პაროლი, რომლითაც Guardian-ში შედიხართ. ამ პროცესში მხოლოდ ერთხელ მოგეთხოვებათ.

## 2. შეიყვანეთ გასაღები ავთენტიფიკატორში

აირჩიეთ ხელით დაყენება და შეიყვანეთ ნაჩვენები გასაღები. გამოიყენეთ SHA-1, ექვსი ციფრი და 30-წამიანი პერიოდი.

## 3. ექვსნიშნა კოდის დადასტურება

შეიყვანეთ აპში ნაჩვენები კოდი. მეორე პაროლი საჭირო არ არის.

## კონფიდენციალურობა: არ შეიყვანოთ საიტის URL

თუ აპი სახელს ან საიტს ითხოვს, მიუთითეთ მხოლოდ „ΩGuardian“ ან ნეიტრალური სახელი. არ შეიყვანოთ თქვენი Symfony ინსტანციის URL.

შეინახეთ საიდუმლოდ: გასაღებით შესაძლებელია TOTP კოდების გენერირება. ნუ გააზიარებთ და ნუ გადაიღებთ ეკრანს.

დროებითი საიდუმლო იწურება 10 წუთის ან 5 არასწორი კოდის შემდეგ; დაიწყეთ თავიდან. შეცდომა ინარჩუნებს ფორმას პაროლის ხელახალი მოთხოვნის გარეშე. დადასტურების მრიცხველი გამოიყენება განმეორების წინააღმდეგ.

## აღდგენა და შემოწმება

შლის username-ის TOTP საიდუმლოსა და მრიცხველს, აუქმებს სესიებს და აღრიცხავს მოქმედებას. დაარეგისტრირეთ ახალი ავთენტიფიკატორი; საერთო MFA მოთხოვნა რჩება და შეიძლება პროფაილერი დაბლოკოს.


```bash
php bin/console guardian:mfa:reset admin --env=dev
```
