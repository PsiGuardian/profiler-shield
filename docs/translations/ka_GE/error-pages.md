## საჯარო შეცდომის გვერდები

შეინარჩუნეთ აპლიკაციის გვერდები ან აჩვენეთ ნეიტრალური HTML. რეალური HTTP სტატუსის კოდები არ იცვლება.

საწყის რეჟიმში შეცდომებს Symfony აჩვენებს. ზოგადი რეჟიმი მორგებულ ტექსტს უგულებელყოფს. მხოლოდ მორგებული რეჟიმი იყენებს სტუმრის შეტყობინებას. საჯარო მითითება შეიძლება არ იყოს, იყოს შემთხვევითი ან ფიქსირებული; იგი ტექსტისგან დამოუკიდებელია. HTTP კოდები არ იცვლება.

აპლიკაციის რეჟიმი ინარჩუნებს საიტის 404 პასუხებს; გამონაკლისებისთვის გამოიყენება მისი 404 შაბლონი, თუ არსებობს, სხვაგვარად — ნეიტრალური გვერდი. ნეიტრალური რეჟიმი აჩვენებს სტანდარტულ ტექსტს, მორგებული რეჟიმი — თქვენს ტექსტს.

ანონიმური 500 გამონაკლისი იღებს ნეიტრალურ გვერდს. დეტალებს სჭირდება უფლებამოსილი Guardian იდენტობა და GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=1. დაკარგული ან დაზიანებული Twig შაბლონი ცვლის პასუხს ნეიტრალურით; საკუთარი შეცდომის კონტროლერი ცალკე ინტეგრაციას საჭიროებს. JSON და წარმატებული ბიზნესგვერდები უცვლელია.

| error_mode | პარამეტრები |
|---|---|
| native | აპლიკაციის რეჟიმი ინარჩუნებს საიტის 404 პასუხებს; გამონაკლისებისთვის გამოიყენება მისი 404 შაბლონი, თუ არსებობს, სხვაგვარად — ნეიტრალური გვერდი. ნეიტრალური რეჟიმი აჩვენებს სტანდარტულ ტექსტს, მორგებული რეჟიმი — თქვენს ტექსტს. |
| generic | HTML 400–599 → შეინარჩუნეთ აპლიკაციის გვერდები ან აჩვენეთ ნეიტრალური HTML. რეალური HTTP სტატუსის კოდები არ იცვლება. |
| custom | მხოლოდ მორგებული ნეიტრალური შეტყობინების რეჟიმში. რეჟიმის შეცვლისას თქვენი ტექსტი ინახება. (≤360 Unicode) |
| error_reference | none / random / custom |
| error_reference_text | ხელმისაწვდომია მხოლოდ მორგებული ფიქსირებული მითითებისთვის. |
| error_custom_text | მხოლოდ მორგებული ნეიტრალური შეტყობინების რეჟიმში. რეჟიმის შეცვლისას თქვენი ტექსტი ინახება. |

## ნაჩვენები მითითება

განსხვავებულმა შეტყობინებებმა ან მუდმივმა მითითებებმა შეიძლება რეალური შეცდომა გამოავლინოს. HTTP კოდების გაყალბება დაუშვებელია.

მინიშნება გამოიყენება Guardian-ის ნეიტრალურ გვერდებზე: შემთხვევითი რეჟიმი ქმნის ახალ კოდს და არა შემთხვევით შეტყობინებას. ეს კოდი ჟურნალის ჩანაწერებთან დასაკავშირებელი იდენტიფიკატორი არ არის.

არჩევანი შენახვამდე სერვერზე მოწმდება.

```text
templates/bundles/TwigBundle/Exception/error404.html.twig
templates/bundles/TwigBundle/Exception/error.html.twig
GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=1

HTTP 400 / 403 / 404 / 429 / 500 / 503
application/json → application/json; application/problem+json → application/problem+json
HTML 2xx → HTML 2xx
HTTP 404 → HTTP 404; HTTP 500 → HTTP 500
```

## ქსელი და განთავსება

IP სია იღებს IPv4, IPv6 მისამართებსა და CIDR ქსელებს. ჩართვამდე შეამოწმეთ Symfony-ის სანდო პროქსები. უსაფრთხო ქუქიებისთვის გამოიყენეთ HTTPS. Guardian არ ასწორებს საჯაროდ გახსნილ ვებსერვერს ან მონაცემთა ბაზას.

უარყავით დიაგნოსტიკა, თუ იდენტობა, როლი, სესია, ქსელი, განრიგი, JIT ან ბლოკი ვერ მოწმდება. ბრაუზერი ვადის გასვლას არ წყვეტს. შეგროვება და ნახვა დამოუკიდებელია. მოწყობილობის დამახსოვრება ავთენტიფიკაცია არ არის. საგანგებო წვდომას სჭირდება იდენტობა, გამოყენებული კოდი და მდგრადი აუდიტი; კრიტიკული აუდიტის შეცდომა გახსნას კრძალავს. არასწორი კონფიგურაცია ნაწილობრივ არ გამოიყენოთ. არჩევითი კონტროლი გარე სერვისს არ მოითხოვს.
