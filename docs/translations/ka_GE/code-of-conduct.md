# ქცევის კოდექსი

[დოკუმენტაციის სარჩევი](README.md)

ისაუბრეთ პატივისცემით, ზუსტად და ფაქტებით. აკრძალულია შევიწროება, პირადი თავდასხმა, პირადი მონაცემები და შეუთანხმებელი დაუცველობის გასაჯაროება. პასუხისმგებლებს შეუძლიათ მოდერაცია და ანგარიშების შეზღუდვა. მგრძნობიარე ცნობები უსაფრთხოების პოლიტიკას მიჰყვება.
