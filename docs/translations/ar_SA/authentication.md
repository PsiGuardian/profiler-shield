# Sign-ins وكلمات المرور

[فهرس الوثائق](README.md)


## الحسابات والتسجيل الأول

مرحبا بكم في غارديان. كلمة المرور الأولية مؤقتة. اختر سر جديد: يبقى لوحة التشخيص مغلقة حتى تفعل ذلك. يتم إزالة ملف الاعتماد الأولي بعد التحقق.

Guardian الحسابات منفصلة عن حسابات الموقع. يحتاج الحساب الأولي والحسابات الجديدة إلى تغيير كلمات المرور الخاصة بهم قبل المضي قدما. رؤية دور الأمن يسمح للمعلومات دون إمكانية الوصول إلى ملفات تعريف الشخصيات. تغير دور أو كلمة مرور يلغي الجلسات السابقة.

يجهّز المسار الخاص والمفتاح والخزنة وملفات Symfony ومسؤولًا عند الحاجة. يحفظ الحسابات الموجودة. يرفض بيئة الإنتاج. بعد التشغيل المباشر امسح الذاكرة المؤقتة ونفّذ الفحوص.


```bash
php bin/console guardian:access --env=dev
```


| متطلبات كلمة المرور المحفوظة | الحد الأدنى (Unicode الشخصيات ) |
|---|---|
| initial-admin-credentials.txt | 0600; random_int; &gt;=32 |
| password_policy[min_length] | 8–64; 15 |
| input | Unicode; ≤512 UTF-8 B |
| Argon2id | PHP + Argon2id → Argon2id |
| bcrypt | PHP − Argon2id → bcrypt; ≤72 UTF-8 B |

## سياسة كلمة المرور

تنطبق هذه القواعد على إنشاء كلمة المرور وتغييرها، على شبكة الإنترنت وفي CLIلا يكشفون أو يفحصون كلمات المرور الموجودة.

القيمة الأصلية : 15 استخدام كلمة مرور فريدة أو مدير كلمة المرور.فئات الشخصيات المطلوبة لا تضمن كلمة مرور غير متوقعة.

على هذا الخادم، Guardian يستخدم تلقائيًا Argon2id للحصول على كلمات المرور الجديدة.حافظ عليها PHP الحد الأقصى للتطبيق: الحد المحدود للطلب هو 512 UTF-8 بيوت

هذا PHP الخادم لا يقدم Argon2id. Guardian وبالتالي يستخدم bcrypt ورفض كلمات المرور تتجاوز 72 UTF-8 بيوت: اطلب من مدير النظام إمكانية Argon2id الدعم في PHP.

هذا الخيار يلغي على الفور الجلسات الموجودة، بما في ذلك الخاص بك. يحتاج الحسابات إلى تغيير كلمات المرور الخاصة بهم قبل تكوين Guardian أو فتح التشخيص.

يغيّر كلمة مرور حساب username الموجود بإدخال مخفي وفق السياسة، ويلغي كل جلساته ويسجل الإجراء. لا تمرر كلمة المرور كوسيط.

## القفل التقدمية

كل مرحلة يحدد حدود الفشل، وحساب النافذة، ومدة القفل، وتكرار النافذ. 10 الفشل يؤدي إلى 10يمكن أن تؤدي الفشل المتكرر إلى المرحلة التالية.تغطي عمليات التحقق كل من الحساب وأصل الشبكة، بما في ذلك تأكيدات المدير.

عدادات مشفرة مستقلة للحساب المطبّع والمصدر؛ لا تُحفظ عناوين IP الخام. يسبق التجزئة حجز ذري ينتهي بعد 120 ثانية. الحجز المهجور يُحسب فشلًا؛ النتائج المتأخرة لا تنشئ جلسات. CSRF غير الصحيح لا يحجز شيئًا. الدخول الناجح يمسح فشل الحساب ويحفظ تاريخ التكرار والمصدر. عند 10000 إدخال نشط تُرفض الهويات الجديدة بدل إزاحة الحظر.

يتم تشغيل المراحل في ترتيب.بعد إغلاق ، تستخدم الفشل الجديد داخل نافذة التكرار المرحلة التالية.خارج تلك النافذة ، تنطبق المرحلة الأولى مرة أخرى.تكرر المرحلة الأخيرة.لا تمدد الطلبات المحظورة التأخير. 8 مرحلة الانتعاش المحلي: guardian:login:unlock --all.

| المرحلة | متطلبات كلمة المرور المحفوظة |
|---|---|
| الفشل قبل القفل | 1–100 |
| الدقائق ( دقائق ) | 1–10080 |
| حساب النوافذ ( دقائق ) | 1–1440 |
| تكرار النافذة بعد إلغاء القفل (دقائق) | 1–10080 |
| المرحلة | 1–8; block[n+1] ≥ block[n] |
| القيمة الأولية | 10 / 10 / 30 / 30 |
| 5 → 10 min; 5 → 2 h | 5 / 10 / 30 / 30 → 5 / 120 / 30 / 30 |
| HTTP | 429; Retry-After |

## مختبر تكلفة البحث الكامل

مقارنة بشكل متساو أسرار عشوائية من طول ثابت دون إدخال كلمة مرور حقيقية.معدلات التفكير وأسعار الأجهزة هي افتراضات قابلة للتعديل.لا يتم إرسال محاولات تسجيل الدخول.

تستخدم الحسابات فئات ASCII منفصلة وBigInt. يعطي مبدأ الشمول والاستبعاد فضاء البحث الدقيق؛ غياب فئة أو قصر الطول يعطي صفرًا. متوسط الرتبة دون إحلال هو (N+1)/2. تشمل مدة الحظر المتوقعة العتبات وتكرار المرحلة الأخيرة. يُعطل التقدير إن لم تناسب السرعة النوافذ. كلفة العمل دون اتصال هي الساعات مضروبة في السعر المفترض للساعة.

مع الحروف الثابتة ، يقلل من عدد الأسرار المتوافقة التي تتطلب فئة.توسع الحروف هو عمل مختلف.يفترض أوقات القفل التخمينات المستمرة سريعة بما فيه الكفاية للبقاء داخل النوافذ المعدلة.

هذا النموذج لا يقيس قوة كلمة المرور المختارة من قبل الإنسان. فإنه يستبعد القاموس، وإعادة الاستخدام، والهروب والاستراتيجيات المستهدفة. قفل الويب لا يحمي الألواح المسروقة. CPU القياس : guardian:password:benchmark.

الأرقام الكبيرة مكتوبة بالكامل، مع تجميع الرقم وبدون تصنيف E. الزمن والتكاليف مستديرة.

| الأبجدية المتاحة | أسرار متوافقة محتملة |
|---|---|
| ASCII أسفل القضية | 26 |
| ASCII أعلى | 26 |
| ASCII الرقم | 10 |
| ASCII الرموز التي تستبعد الفضاء | 32 |
| أسعار الفائدة المقررة عبر الإنترنت (الضيوف/الأجانب) | 1 / s |
| أسعار الفائدة غير المباشرة (Hashes/s) | 10000 / s |
| تكلفة الأجهزة المطلوبة (€/ساعة) | 2 € / h |

```bash
php bin/console guardian:password:benchmark --iterations=3 --env=dev
```

## العودة والتحقق

انسخ الخزنة والمفتاح معًا واختبر الاستعادة. لا تُعاد توليد المفاتيح المفقودة تلقائيًا. بعد الإزالة افحص أداة التحليل في بيئة خاصة فقط. الإنتاج: APP_DEBUG=0 مع تعطيل WebProfilerBundle وجمع البيانات. سلسلة التدقيق المحلية لا تثبت سلامة مضيف مخترق.

يصفّر عدادات username. يمسح --ip العنوان عداد مصدر IPv4/IPv6 أيضًا؛ وإلا قد يبقى حظر الشبكة. يمسح --all جميع العدادات. لا تتغير الحسابات أو كلمات المرور أو الجلسات؛ ويُسجّل الإجراء.
