## صفحات الخطأ العام

احتفظ بصفحات التطبيق أو اعرض HTML محايدًا للزوار. تبقى رموز حالة HTTP الحقيقية دون تغيير.

الأزياء الأصلية تسمح Symfony الإشارة العامة يمكن أن تكون غائبة، عشوائية أو ثابتة؛ فهي مستقلة عن الرسالة. HTTP لا تزال رموز الحالة غير متغيرة.

صفحة التطبيق: يحافظ على الموقع الحالي 404 الإجابة: الاستثناءات تستخدم 404 نموذج عندما يكون متاحا، وإلا صفحة محايدة.محايد: الرسالة القياسية.مخصص: تستخدم النص الخاص بك.

تتلقى استثناءات 500 المجهولة صفحة محايدة. التفاصيل تتطلب هوية Guardian مخولة وGUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=1. قوالب Twig المفقودة أو المعطلة تستخدم العرض المحايد؛ وحدات تحكم الأخطاء الخاصة تحتاج تكاملًا مستقلًا. لا تتغير استجابات JSON وصفحات العمل الناجحة.

| error_mode | الإعدادات |
|---|---|
| native | صفحة التطبيق: يحافظ على الموقع الحالي 404 الإجابة: الاستثناءات تستخدم 404 نموذج عندما يكون متاحا، وإلا صفحة محايدة.محايد: الرسالة القياسية.مخصص: تستخدم النص الخاص بك. |
| generic | HTML 400–599 → احتفظ بصفحات التطبيق أو اعرض HTML محايدًا للزوار. تبقى رموز حالة HTTP الحقيقية دون تغيير. |
| custom | متاح فقط للرسالة المحايدة المخصصة. يُحفظ النص عند تغيير الوضع. (≤360 Unicode) |
| error_reference | none / random / custom |
| error_reference_text | متاحة فقط مع إشارة ثابتة مخصصة. |
| error_custom_text | متاح فقط للرسالة المحايدة المخصصة. يُحفظ النص عند تغيير الوضع. |

## المرجع المعروض

قد تكشف الرسائل المختلفة أو المراجع الثابتة عن الخطأ الحقيقي. يجب عدم تزوير رموز HTTP.

هذا الإشارة ينطبق على Guardianالصفحات المحايدة: يولد عن طريق الصدفة رمزًا جديدًا وليس رسالة عشوائية.

تُتحقق الخيارات على الخادم قبل حفظها.

```text
templates/bundles/TwigBundle/Exception/error404.html.twig
templates/bundles/TwigBundle/Exception/error.html.twig
GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=1

HTTP 400 / 403 / 404 / 429 / 500 / 503
application/json → application/json; application/problem+json → application/problem+json
HTML 2xx → HTML 2xx
HTTP 404 → HTTP 404; HTTP 500 → HTTP 500
```

## الشبكة والتنفيذ

IP يسمح القائمة تقبل IPv4, IPv6 و CIDR الشبكات - التحقق Symfony إعداد بروكسي موثوق به قبل تمكينها.استخدام HTTPS الكوكيز الآمنة Guardian لا تقوم بإصلاح خوادم الويب أو قواعد البيانات المعروضة.

ارفض التشخيص إذا تعذر فحص الهوية أو الدور أو الجلسة أو الشبكة أو الجدول أو JIT أو القفل. المتصفح لا يقرر انتهاء الصلاحية. جمع الملفات وعرضها منفصلان. تذكر الجهاز لا يصادق عليه. الطوارئ تتطلب هوية ورمزًا مستهلكًا وتدقيقًا دائمًا؛ فشل التدقيق الحرج يمنع الفتح. لا تطبق إعدادًا غير صحيح جزئيًا. الضوابط الاختيارية لا تفرض خدمة بعيدة.
