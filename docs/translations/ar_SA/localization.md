# الترجمات

[فهرس الوثائق](README.md)

توفر البوابة 28 صيغة إقليمية و25 كتالوجًا؛ تتشارك الصيغ الإنجليزية الأربع كتالوجًا واحدًا. تُترجم النصوص الثابتة ثم تُهَرَّب بأمان. لا تُترجم أسماء المستخدمين أو الرسائل المخصصة أو بياناتهم. لا تتلقى خدمة بعيدة النصوص. يفحص التدقيق المفاتيح والمعاملات وUTF-8 والأوامر والروابط؛ وتزور اختبارات HTTP صفحات كل صيغة.
```bash
php tests/translation_audit.php --strict
php tests/documentation_audit.php
composer test
```
