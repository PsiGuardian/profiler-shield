# سياسة الأمان

[فهرس الوثائق](README.md)

أبلغ عن الثغرات خصوصيًا إلى bundle-sec@omegaguardian.fr للاتفاق على قناة مشفرة. لا أسرار أو رموز نشطة أو روابط خاصة في الرسالة الأولى. اذكر إصدارات Guardian وSymfony وPHP والأثر والمتطلبات وأقل خطوات إعادة الإنتاج. يؤكد المشرفون الاستلام ويفحصون ويصلحون خصوصيًا ويختبرون وينسقون الإعلان والتصحيح.

لا ترسل أبدًا كلمات المرور أو أسرار TOTP أو مفاتيح التشفير أو روابط التشخيص عبر البريد الإلكتروني.

انسخ الخزنة والمفتاح معًا واختبر الاستعادة. لا تُعاد توليد المفاتيح المفقودة تلقائيًا. بعد الإزالة افحص أداة التحليل في بيئة خاصة فقط. الإنتاج: APP_DEBUG=0 مع تعطيل WebProfilerBundle وجمع البيانات. سلسلة التدقيق المحلية لا تثبت سلامة مضيف مخترق.
