# サインインとパスワード

[ドキュメント目次](README.md)


## アカウントと最初のサインイン

ガーディアンへようこそ. 最初のパスワードは一時的です. 新しい秘密を選択してください: パネルと診断が閉鎖されるまで。

Guardian アカウントはサイトのアカウトから分離されます. 最初のア カウントと新しいアカウンターは継続する前にパスワードを変更しなければなりません. セキュリティ ロール ビューは、プロフィールへのアクセスなしに情報を許可します. 役割やパスポートを変更すると、以前のセッションが無効になります。

非公開パス、鍵、保管庫、Symfony ファイルを準備し、管理者がいなければ作成します。既存アカウントを保持します。本番環境を拒否します。直接実行後はキャッシュを消去して検証します。


```bash
php bin/console guardian:access --env=dev
```


| 保存パスワード要件 | 最小限(Unicode キャラクター) |
|---|---|
| initial-admin-credentials.txt | 0600; random_int; &gt;=32 |
| password_policy[min_length] | 8–64; 15 |
| input | Unicode; ≤512 UTF-8 B |
| Argon2id | PHP + Argon2id → Argon2id |
| bcrypt | PHP − Argon2id → bcrypt; ≤72 UTF-8 B |

## パスワード政策

これらのルールは、パスワードの作成および変更に適用されます。 CLI既存のパスワードを明らかにしたり検証したりしない。

初期価値: 15 キャラクター. ユニークなパスワードまたはパスポートマネージャーを使用します. 必要なキャラクトカテゴリは、予測不可能なパスを保証しません。

このサーバーでは、 Guardian 自動利用 Argon2id 新しいパスワードを保存する PHP 応募制限:応募限定 512 UTF-8 バイト

この PHP サーバーは提供しない。 Argon2id. Guardian したがって使用 bcrypt パスワードを超えることを拒否する 72 UTF-8 バイト:システム管理者に許可を求める Argon2id サポート中 PHP.

このオプションは、既存のセッションを即座にキャンセルします. アカウントはガーディアン設定または診断を開く前にパスワードを変更する必要があります。

既存の username のパスワードを現在のポリシーに従う非表示入力で変更し、全セッションを取り消して記録します。パスワードを引数にしないでください。

## 進歩的なロック

各段階は、失敗の制限を定義し、ウィンドウを数え、閉鎖期間と繰り返すウィンターを計算します。 10 失敗を引き起こすA 10-minute lockout. 繰り返し失敗が次の段階を引き起こす可能性があります. チェックはアカウントとネットワークの起源、管理者の確認を含む両方をカバーします。

暗号化カウンターは正規化されたアカウントと送信元で独立し、生の IP は保存しません。ハッシュ前にアトミック予約を行い、120 秒で失効します。放棄予約は失敗に数え、遅れた結果はセッションを作りません。不正 CSRF は予約しません。ログイン成功はアカウントの失敗を消しますが再発・送信元履歴は保持します。活動中の 10000 件に達すると、制限記録を追い出さず新規 ID を拒否します。

ステージは順序で実行されます。ブロック後、繰り返しウィンドウ内の新しい失敗は次のステージを使用します. そのウィンターの外では、最初のステージが再び適用されます. 最後の段階が繰り返される. 封鎖されたリクエストは遅延を拡大しない。 8 地元の回復: guardian:login:unlock --all.

| ステージ | 保存パスワード要件 |
|---|---|
| ロックアップ前の失敗 | 1–100 |
| ロックアウト(数分) | 1–10080 |
| ウィンドウ数(分) | 1–1440 |
| オフロック後のウィンドウを繰り返す(分) | 1–10080 |
| ステージ | 1–8; block[n+1] ≥ block[n] |
| 初期値 | 10 / 10 / 30 / 30 |
| 5 → 10 min; 5 → 2 h | 5 / 10 / 30 / 30 → 5 / 120 / 30 / 30 |
| HTTP | 429; Retry-After |

## 検索コスト実験室

真のパスワードを入力せずに固定長さのランダムな秘密を均一に比較します. 見積もり率とハードウェア価格は調整可能な仮定です. サインイン試みが送られません。

互いに素な ASCII カテゴリと BigInt を使います。包除原理で正確な検索空間を計算し、カテゴリ不足や短すぎる長さはゼロです。重複なしの平均順位は (N+1)/2。待機時間の期待値はしきい値と最後の段階の繰り返しを含みます。速度が時間枠に合わなければ推定を無効にします。オフライン費用は時間数と仮定の時間単価の積です。

固定アルファベットで、カテゴリを必要とすることは、合致する秘密の数を減らします. アルファベルを拡張することは別の操作です. ロックタイムは、構成されたウィンドウの中に滞在するのに十分に速い継続的な推測を取ります。

このモデルは、人によって選ばれたパスワードの強さを測定しません。それは辞書、再利用、漏れ、ターゲット戦略を排除します. ウェブロックは盗まれたハッシュを保護しない。 CPU 測定: guardian:password:benchmark.

大きな数字は、数値のグループ化とEノートなしで完全に書かれています。時間とコストが丸められています.同じ順位を同じ仮定を使用して比較します。

| 利用可能シミュレーションアルファベット | 可能な秘密 |
|---|---|
| ASCII 低いケース | 26 |
| ASCII トップページ | 26 |
| ASCII デジタル | 10 |
| ASCII スペースを排除するシンボル | 32 |
| オンライン料金(ゲーセス/s) | 1 / s |
| オフライン料金(ハッシュ/s) | 10000 / s |
| ハードウェア料金(時間/ユーロ) | 2 € / h |

```bash
php bin/console guardian:password:benchmark --iterations=3 --env=dev
```

## 回復と検証

保管庫と鍵を一緒に保存し、復元をテストしてください。失った鍵は自動再生成しません。削除後のプロファイラー確認は非公開環境のみ。本番は APP_DEBUG=0、WebProfilerBundle と収集を無効化します。侵害されたホストのローカル監査チェーンは完全性を保証しません。

username のカウンターをリセットします。--ip アドレス は IPv4/IPv6 送信元のカウンターも消去します。指定しないと送信元の制限が残る場合があります。--all は全カウンターを削除します。アカウント、パスワード、セッションは変更せず記録します。
