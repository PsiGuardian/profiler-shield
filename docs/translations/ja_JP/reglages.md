## 追加の保護

保護機能は関連設定とまとめています。無効な項目はグレー表示ですが、値は保持されます。

Guardian プロフィールとデビューツールバーを制御します. 有効な管理者または開発者のアカウントが必要です。 MFAスケジュール、 JIT, ネットワーク制限およびロックダウンはまだアクセスを拒否する可能性があります. Stealth モードは入力ポイントを隠し、これらのチェックを置き換えることはありません。


```text
POST ∧ CSRF ∧ role=admin ∧ password
```


| 設定プロファイル | 設定 |
|---|---|
| ソロ · 柔軟性 | solo: mfa=false; schedule=false; jit=false; idle=60 min; absolute=8 h; remember=14 d |
| チーム · 強化 | team: mfa=true; schedule=false; jit=false; idle=45 min; absolute=8 h; remember=7 d |
| 敏感・制限 | strict: mfa=true; schedule=true; jit=true; idle=15 min; absolute=4 h; remember=1 d |

| パラメーター | 設定 | 初期値 |
|---|---|---|
| `stealth` | 未承認の診断ルートでは 403 ではなく 404 を返します。 | `true` |
| `mfa` | 必須 MFA を有効にする前に全ユーザーが TOTP を登録する必要があります。 | `false` |
| `idle_minutes` | 操作がない場合、セッションが切れるまでの分数。 | `60` |
| `absolute_hours` | 操作の有無に関係なく時間単位で指定します。 | `8` |
| `remember_days` | 日数。ログインや勤務時間の規則を置き換えません。 | `14` |
| `schedule_enabled` | 診断ツールを利用できる時間を選びます。アプリケーションのページは引き続き利用できます。 | `false` |
| `weekdays` | 診断を許可する曜日を選んでください。 | `1,2,3,4,5` |
| `start` | 開始 | `09:00` |
| `end` | 終了 | `18:00` |
| `timezone` | このページを処理する PHP プロセスから検出しました。PHP CLI、PHP-FPM、OS のタイムゾーンは異なる場合があります。保存前にサーバー設定を確認してください。 | `OS / PHP CLI` |
| `portal_closed_outside_hours` | 時間外は非公開 URL が 404 を返します。復旧はローカル CLI のみです。 | `false` |
| `jit_enabled` | 申請された診断時間枠だけ Profiler を開放します。 | `false` |
| `jit_minutes` | 分単位。有効な場合のみ使用します。 | `30` |
| `ip_allowlist` | 注意: 誤った設定はアクセス不能につながります。ローカル復旧: guardian:policy:reset。 | `∅` |
| `audit_level` | 監査の詳細度とローカル保存期間を選択します。 | `standard` |
| `audit_retention_days` | ログ消去までの日数。 | `30` |
| `alert_email` | 緊急警告の送信先です。アクセスはメール配信に依存してはいけません。 | `∅` |
| `emergency_enabled` | 一度限りのコードと監査記録を伴う 30 分の例外を許可します。 | `false` |
| `login_rules` | デフォルト: 10 失敗、その後A 10-minute lockout. 会計は、パスワード確認を含むアカウントおよびネットワークの起源に適用されます。 | `10 / 10 / 30 / 30` |
| `password_policy` | これらのルールは、パスワードの作成および変更に適用されます。 CLI既存のパスワードを明らかにしたり検証したりしない。 | `min_length=15` |
| `error_mode` | アプリケーションページ:既存のサイトを保存する 404 答え:例外利用 404 テンプレートが利用可能であれば、中立なページです。中立:標準メッセージ.カスタマイズ:あなたのテキストを使用します。 | `native` |
| `error_reference` | この参照は、 Guardianニュートラルページ:ランダムで新しいコードを生成し、偶然のメッセージではない。 | `none` |
| `error_reference_text` | 単にカスタマイズされた静的参照で利用できます。 | `∅` |
| `error_custom_text` | カスタムの中立メッセージでのみ使用できます。モードを変更してもテキストは保持されます。 | `∅ → custom` |

スケジュール、選択日、包括的なスタート時間および独占的な終了時間を可能にします。保存されたタイムゾーンは地元の時間を決定します.夜間の間隔は受け入れられません.時間外のポータルを隠すことは、遠隔緊急アクセスを妨げます。

非アクティブ時の期限、絶対有効期間、端末の記憶には異なる役割があります。端末を記憶しても時間制限や JIT は回避できません。取り消すとサーバー側で対象のセッションが終了します。ログで操作を識別できるよう個別のアカウントを使ってください。

JIT 許可されたセッションから一時的なウィンドウを有効にする必要があります. 緊急アクセスが有効になった場合、パスワード、単用コードおよび理由が必要です. それはグローバルロックダウンを超えない。

IP許可リストが承認 IPv4, IPv6 そして、 CIDR ネットワークチェック Symfony 信頼できるプロキシの設定を有効にする前に。 HTTPS 安全なクッキーのために Guardian 暴露されたウェブサーバーやデータベースを修理しない。

レベルと維持は、利用可能なイベントを決定し、 5000 入力. ページを変更する前にタイプとアカウントによってフィルタリング. アラームが表示されます; 輸送および配達を設定します. 地元のハッシュチェーンは、損なわれたホストの完全性を保証しません。

最低限の長さと必要なカテゴリを設定する 接続およびパスワード. アカウント作成バーグは保存されたポリシーを説明します. 新しいパスポートに適用される変更; 既存のアカウンのための義務更新を選択します。 Guardian 選択 Argon2id いつ PHP それを提供する、そうでないと bcrypt.

タイプおよびアカウントによって保存されたすべてのイベントをフィルタリングします. 新しいイベントが最初に表示されます。 50Scrolling は次のページをロードしない。

## 環境


```dotenv
GUARDIAN_LOGIN_PATH=/internal/<random-48-hex>
GUARDIAN_ENCRYPTION_KEY=<64-hex>
GUARDIAN_STORAGE_DIR=<private-directory>
GUARDIAN_COLLECTION_BRIDGE=0
GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=0
GUARDIAN_SHOW_PHP_VERSION=0
```


プロキシは TLS、正規化、大量通信への防御を担当します。ゲートウェイはルーティング前に診断を検査し、業務ルートではアカウントやセッションを読みません。Guardian の ID は Symfony と独立しています。保管庫と鍵を一緒に公開ディレクトリ外へバックアップしてください。PHP やホストの侵害で両方が漏れる可能性があります。保存先は単一ホストです。起動、キャッシュ、プロキシの障害はアプリ全体に影響し得ます。

保管庫と鍵を一緒に保存し、復元をテストしてください。失った鍵は自動再生成しません。削除後のプロファイラー確認は非公開環境のみ。本番は APP_DEBUG=0、WebProfilerBundle と収集を無効化します。侵害されたホストのローカル監査チェーンは完全性を保証しません。

## 回復と検証

IP リストを空にし、予定、JIT、遠隔緊急アクセスを無効化します。認証、MFA、全体ロック、ログイン制限は残ります。復旧後に必要な制限を設定し直してください。

on は診断を閉じて全セッションを削除します。業務ページは動作します。off は全体ロックのみ解除します。再ログインが必要で、他のポリシーは有効です。


```bash
php bin/console guardian:policy:reset --env=dev
php bin/console guardian:lockdown on --env=dev
php bin/console guardian:doctor --env=dev
```
