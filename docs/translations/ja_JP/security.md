# セキュリティ方針

[ドキュメント目次](README.md)

脆弱性は bundle-sec@omegaguardian.fr に非公開で連絡し、暗号化した経路を相談します。最初の連絡に秘密、有効なトークン、非公開 URL を添付しないでください。Guardian、Symfony、PHP の版、影響、前提、最小再現を記載します。管理者が受領、調査、非公開修正、テストを行い、告知と修正を調整します。

パスワード、TOTP シークレット、暗号鍵、診断 URL をメールで送信しないでください。

保管庫と鍵を一緒に保存し、復元をテストしてください。失った鍵は自動再生成しません。削除後のプロファイラー確認は非公開環境のみ。本番は APP_DEBUG=0、WebProfilerBundle と収集を無効化します。侵害されたホストのローカル監査チェーンは完全性を保証しません。
