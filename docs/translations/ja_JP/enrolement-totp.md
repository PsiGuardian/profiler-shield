# 二要素認証

[ドキュメント目次](README.md)


## 二要素認証

外部 QR サービスを使わず、一時コードで Guardian アカウントを保護します。

各人が自己登録 TOTP 秘密とコードを確認します。 MFA 登録されていないアカウントへのアクセスプロファイルのブロック。 QR コードはポータルに位置し、管理回復を計画する前にチーム全体のためにこの保護を必要とします。

## 1. 本人確認

Guardian のログインで使うパスワードを入力します。この設定での入力は一度だけです。

## 2. この QR を認証アプリで読み取る

Guardian がローカルで QR を生成し、外部サービスへリクエストを送信しません。

## 3. 6 桁のコードを確認

認証アプリに表示されたコードを入力してください。パスワードの再入力は不要です。

## プライバシー: サイト URL を入力しないでください

アプリが名前やサイトを求めたら「ΩGuardian」または中立的な別名だけを入力してください。Symfony インスタンスの URL は入力しないでください。オンライン QR 生成サービスは秘密鍵を受け取るため使用しないでください。

秘密に保ってください。TOTP コードを生成できるため共有やスクリーンショットは避けてください。

仮秘密は 10 分または 5 回の誤コードで失効し、設定をやり直します。誤コードでもフォームを保持し、パスワードを再要求しません。確認カウンターは再利用防止で消費します。SVG QR は bacon/bacon-qr-code と ext-iconv を使い、GD、XMLWriter、ネットワークは不要です。手動入力も可能です。otpauth URI は中立の提供者名とアカウントで、サイトのドメインは含みません。秘密と非公開 URL を共有しないでください。

## 回復と検証

username の TOTP 秘密とカウンターを削除し、セッションを取り消して記録します。新しい認証器を登録してください。全体の MFA 要件は残り、プロファイラーを引き続き制限する場合があります。


```bash
php bin/console guardian:mfa:reset admin --env=dev
```
