# Зан үйлийн дүрэм

[Баримт бичгийн агуулга](README.md)

Хүндэтгэлтэй, тодорхой, баримттай ярилцана. Дарамт, хувийн дайралт, хувийн өгөгдөл болон уялдаагүй эмзэг байдлын нийтлэл хориотой. Хариуцагч хэлэлцүүлгийг зохицуулж бүртгэл хязгаарлаж болно. Мэдрэмтгий мэдээлэл аюулгүй байдлын бодлогыг дагана.
