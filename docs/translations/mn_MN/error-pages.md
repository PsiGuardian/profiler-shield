## Дараа нь: Public error pages

Аппын хуудсыг хадгалах эсвэл зочдод саармаг HTML харуулна. Жинхэнэ HTTP төлөвийн кодууд өөрчлөгдөхгүй.

Үндсэн горимд Symfony алдааг харуулна. Ерөнхий горим өөрчилсөн текстийг үл тооцно. Зөвхөн өөрчилсөн горим зочны мэдэгдлийг ашиглана. Нийтийн лавлагаа байхгүй, санамсаргүй эсвэл тогтмол байж болно; текстээс тусдаа. HTTP код өөрчлөгдөхгүй.

Програмын горим нь сайтын 404 хариуг хадгална. Алдаанд 404 загвар байвал ашиглана, үгүй бол саармаг хуудас харуулна. Саармаг горим стандарт мэдэгдэл, өөрчилсөн горим таны текстийг ашиглана.

Нэргүй 500 алдаа саармаг хуудас авна. Дэлгэрэнгүйд зөвшөөрөгдсөн Guardian таних мэдээлэл ба GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=1 шаардлагатай. Twig загвар байхгүй эсвэл алдаатай бол саармаг дүрслэл хэрэглэнэ; өөрийн алдааны контроллер тусдаа холболт шаарддаг. JSON ба амжилттай бизнес хуудас өөрчлөгдөхгүй.

| error_mode | Тохиргоо |
|---|---|
| native | Програмын горим нь сайтын 404 хариуг хадгална. Алдаанд 404 загвар байвал ашиглана, үгүй бол саармаг хуудас харуулна. Саармаг горим стандарт мэдэгдэл, өөрчилсөн горим таны текстийг ашиглана. |
| generic | HTML 400–599 → Аппын хуудсыг хадгалах эсвэл зочдод саармаг HTML харуулна. Жинхэнэ HTTP төлөвийн кодууд өөрчлөгдөхгүй. |
| custom | Зөвхөн өөрчилсөн саармаг мэдэгдэлд ашиглана. Горим солиход текст хадгалагдана. (≤360 Unicode) |
| error_reference | none / random / custom |
| error_reference_text | Үнэгүй хэрэглэгчийн стандарт стандарт стандарт нь хэрэглэж байна. |
| error_custom_text | Зөвхөн өөрчилсөн саармаг мэдэгдэлд ашиглана. Горим солиход текст хадгалагдана. |

## Харагдах лавлагаа

Өөр өөр мэдэгдэл эсвэл тогтмол лавлагаа нь бодит алдааг илчилж болно. HTTP кодуудыг хуурамчаар өөрчилж болохгүй.

Эдүүлбэр нь хэрэглэж байна Guardian’s нейтральный хуудас: алдартай шинэ код, аль нь алдаргүй мэдээ үүсгэхийн тулд. Энэ нь дөрөвдүгээр сарын хоолой холболт тодорхойлолтыг биш юм.

Сонголтыг хадгалахаас өмнө сервер дээр шалгана.

```text
templates/bundles/TwigBundle/Exception/error404.html.twig
templates/bundles/TwigBundle/Exception/error.html.twig
GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=1

HTTP 400 / 403 / 404 / 429 / 500 / 503
application/json → application/json; application/problem+json → application/problem+json
HTML 2xx → HTML 2xx
HTTP 404 → HTTP 404; HTTP 500 → HTTP 500
```

## Network болон ажиллуулах

IP allowlist нь хүлээн зөвшөөрч байна IPv4, IPv6 Үнэгүй CIDR сүлжээний. Check Symfony довертой прокси конфигурацийн өмнө энэ ашиглаж байна. HTTPS Загвартай Cookies. Guardian Энэ вэб сервер болон мэдээллийн баз нь шинэчлэгддэггүй.

Таних мэдээлэл, үүрэг, сесс, сүлжээ, хуваарь, JIT эсвэл түгжээ шалгах боломжгүй бол оношилгоог хориглоно. Хөтөч хугацаа дуусахыг шийдэхгүй. Цуглуулах ба харах тусдаа. Төхөөрөмж санах нь баталгаажуулалт биш. Яаралтай хандалт таних мэдээлэл, хэрэглэсэн код, бат бөх аудит шаарддаг; аудитын ноцтой алдаанд нээхгүй. Буруу тохиргоог хэсэгчлэн хэрэгжүүлэхгүй. Нэмэлт хяналт алсын үйлчилгээ шаардахгүй.
