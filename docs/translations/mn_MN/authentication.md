## Нүүр хуудас / First Sign-in

Guardian-д тавтай морил. Анхны нууц үг түр зуурынх. Шинэ нууц үг сонгох хүртэл самбар болон оношилгоо түгжээтэй байна. Баталгаажсаны дараа анхны нэвтрэх мэдээллийн файл устна.

Guardian Сайтын үйлчлүүлэгчид нь сайт үйлчлэхээс өөрчилж байна. Эхний үйлчлэл, шинэ үйлчүүд нь тэдгээрийг эхлэх өмнө тавтай хэлбэрээр өөрчлөх хэрэгтэй. аюулгүй байдлын үйлчлэгчийн үзэсгэлэн нь өгөгдөлгүй мэдээллийг зөвшөөрөх болно. Энэ үйлчлэгч эсвэл тогтмол хувилбарууд Өмнөд үйлчлийг хязгаарлагддаг.

Хувийн зам, түлхүүр, хадгалалт, Symfony файлууд болон байхгүй бол администратор бэлтгэнэ. Бүртгэлүүдийг хадгална. Үйлдвэрлэлийн орчинд татгалзана. Шууд ажиллуулсны дараа кэш цэвэрлэж шалгалтуудыг ажиллуулна.


```bash
php bin/console guardian:access --env=dev
```


| Хадгалсан нууц үгийн шаардлагууд | Хамгийн бага урт (Unicode тэмдэгт) |
|---|---|
| initial-admin-credentials.txt | 0600; random_int; &gt;=32 |
| password_policy[min_length] | 8–64; 15 |
| input | Unicode; ≤512 UTF-8 B |
| Argon2id | PHP + Argon2id → Argon2id |
| bcrypt | PHP − Argon2id → bcrypt; ≤72 UTF-8 B |

## Нууц үгийн бодлого

Эдгээр дүрэм вэб болон CLI дээр нууц үг үүсгэх, өөрчлөхөд үйлчилнэ. Одоо байгаа нууц үгийг ил болгохгүй, шалгахгүй.

Анхны утга: 15 тэмдэгт. Давтагдашгүй нууц өгүүлбэр эсвэл нууц үгийн менежер ашиглана. Тэмдэгтийн төрлийг шаардах нь урьдчилан таах боломжгүй нууц үгийг батлахгүй.

Энэ сервер дээр Guardian шинэ нууц үгт Argon2id автоматаар ашигладаг. PHP-ийн дэмжлэгийг идэвхтэй байлгана. Програмын хязгаар 512 UTF-8 байт.

Энэ PHP сервер Argon2id дэмжихгүй. Guardian bcrypt ашиглаж, 72 UTF-8 байтаас урт нууц үгийг зөвшөөрөхгүй. Системийн администратороос PHP дээр Argon2id идэвхжүүлэхийг хүснэ үү.

Энэ сонголт одоогийн бүх сессийг, таныхыг ч хүчингүй болгоно. Guardian тохируулах эсвэл оношилгоо нээхээс өмнө нууц үг солих шаардлагатай.

Байгаа username бүртгэлийн нууц үгийг бодлогын дагуу далд оруулж өөрчилнө, бүх сессийг хүчингүй болгож үйлдлийг бүртгэнэ. Нууц үгийг аргументаар бүү дамжуул.

## Шаталсан түгжээ

Хамгийн сүүлийн үеийн дараа нь татаж авахын тулд татаж байх болно. Энэтхэгийн дэлгэрэнгүй мэдээллийг унших уу. 10 Хамгийн сүүлийн үеийн A 10-minute lockout. Дараачийн шагналт эхлэх болно. Checks нь акаунт болон сүлжээний эх үүсвэр, администратор баталгаажуулагч гэх мэт дөрөвдүгээр сар дуусгаж болно.

Шифрлэсэн тоолуур хэвийнжүүлсэн бүртгэл болон эх үүсвэрээр тусдаа; түүхий IP хадгалахгүй. Хэшийн өмнөх атомик захиалга 120 секундэд дуусна. Орхигдсон захиалга алдаанд тооцогдоно; оройтсон үр дүн сесс үүсгэхгүй. Буруу CSRF захиалга хийхгүй. Амжилттай нэвтрэлт бүртгэлийн алдааг арилгана, давталт ба эх үүсвэрийн түүхийг хадгална. 10000 идэвхтэй бичлэгт шинэ таних мэдээллийг татгалзаж, түгжээг хасахгүй.

Шатууд дарааллаар үйлчилнэ. Түгжээ тайлагдсаны дараа давталтын хугацаанд дахин алдаа гарвал дараагийн шат хэрэглэгдэнэ. Хугацаа өнгөрвөл эхний шат дахин үйлчилнэ. Сүүлийн шат давтагдана. Түгжигдсэн хүсэлт хугацааг сунгахгүй. Хамгийн ихдээ 8 шат. Дотоод сэргээх тушаал: guardian:login:unlock --all.

| Шат | Хадгалсан нууц үгийн шаардлагууд |
|---|---|
| Түгжихээс өмнөх алдааны тоо | 1–100 |
| Түгжих хугацаа (минут) | 1–10080 |
| Тоолох хугацаа (минут) | 1–1440 |
| Түгжээ тайлагдсаны дараах давталтын хугацаа (минут) | 1–10080 |
| Шат | 1–8; block[n+1] ≥ block[n] |
| Анхны утга | 10 / 10 / 30 / 30 |
| 5 → 10 min; 5 → 2 h | 5 / 10 / 30 / 30 → 5 / 120 / 30 / 30 |
| HTTP | 429; Retry-After |

## Бүрэн хайлтын өртгийн симулятор

Жинхэнэ нууц үг оруулахгүйгээр ижил урттай, жигд санамсаргүй нууцуудыг харьцуулна. Таах хурд болон төхөөрөмжийн үнэ нь өөрчилж болох таамаглал юм. Нэвтрэх оролдлого илгээхгүй.

Огтлолцохгүй ASCII ангилал ба BigInt ашиглана. Оруулах-хасах аргаар яг хайлтын орон зайг олно; ангилал дутуу эсвэл урт хүрэхгүй бол тэг. Буцаалтгүй дундаж байр (N+1)/2. Хүлээлтийн тооцоо босго болон сүүлийн шатын давталтыг хамарна. Хурд хугацааны цонхонд нийцэхгүй бол тооцоог унтраана. Офлайн өртөг нь цагийг таамаг цагийн үнээр үржүүлсэн утга.

Тэмдэгтийн олонлог тогтмол үед заавал шаардах төрөл нь зөвшөөрөгдөх нууцын тоог бууруулна. Тэмдэгтийн олонлогийг нэмэх нь өөр үйлдэл. Түгжих хугацааны тооцоо нь тохируулсан хугацаанд багтахуйц хурдан, тасралтгүй оролдлогыг таамаглана.

Энэ загвар хүний сонгосон нууц үгийн хүчийг хэмжихгүй. Толь бичиг, дахин хэрэглээ, алдагдал болон чиглэсэн аргыг тооцохгүй. Вэб түгжээ хулгайлагдсан хэшийг хамгаалахгүй. Анхны офлайн хурд нь жишээ бөгөөд хэмжилт биш. CPU-ийн дотоод хэмжилт: guardian:password:benchmark.

Том тоог E тэмдэглэгээгүй, цифрүүдийг бүлэглэн бүтнээр бичнэ. Хугацаа ба өртгийг тоймлоно. Ижил таамаглалтай ижил мөрийг харьцуулна уу.

| Симуляцид ашиглах тэмдэгтүүд | Шаардлага хангасан боломжит нууцууд |
|---|---|
| ASCII жижиг үсэг | 26 |
| ASCII том үсэг | 26 |
| ASCII цифр | 10 |
| Зайнаас бусад ASCII тусгай тэмдэгт | 32 |
| Онлайн таамаг хурд (оролдлого/секунд) | 1 / s |
| Офлайн таамаг хурд (хэш/секунд) | 10000 / s |
| Төхөөрөмжийн таамаг өртөг (€/цаг) | 2 € / h |

```bash
php bin/console guardian:password:benchmark --iterations=3 --env=dev
```

## Загварын болон хяналт

Хадгалалт ба түлхүүрийг хамт нөөцөлж сэргээхийг туршина. Алдсан түлхүүр автоматаар шинээр үүсэхгүй. Устгасны дараа профайлерыг зөвхөн хаалттай орчинд шалгана. Үйлдвэрлэл: APP_DEBUG=0, WebProfilerBundle ба цуглуулалт унтраалттай. Дотоод аудитын гинж халдлагад өртсөн хостын бүрэн бүтэн байдлыг нотлохгүй.

username-ийн тоолууруудыг тэглэнэ. --ip ХАЯГ нь тухайн IPv4/IPv6 эх үүсвэрийн тоолуурыг бас арилгана; үгүй бол сүлжээний түгжээ үлдэж болно. --all бүх тоолуурыг арилгана. Бүртгэл, нууц үг, сесс өөрчлөгдөхгүй; үйлдэл бүртгэгдэнэ.
