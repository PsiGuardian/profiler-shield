## Нэмэлт хамгаалалт

Хамгаалалтын сонголтууд холбогдох тохиргоотойгоо бүлэглэгдсэн. Унтраасан сонголт саарал харагдах ч утга нь хадгалагдана.

Guardian нь профиль болон дебюг хэрэгсэл бар хяналтын. Эдүүлбэртэй администратор эсвэл хөгжүүлэгчийн акаунт шаарддаг. MFAЭнэ нь график, JIT, сүлжээний ограничийг, блокирууд нь одоо ч долооч тусламж болно. Stealth mode hides entry points; it does not replace these checks.


```text
POST ∧ CSRF ∧ role=admin ∧ password
```

Хамгийн сүүлийн үеийн цаг хугацаа, тогтмол өдөр, нэгтгэлийн эхлэх үед болон эксклюзийн дараах цаг хугацааг боломжийг олгодог. Газрын цаг зоны местний цаг хугацаа гэж нэрлэдэг. Өндөр цаг интервалтыг хүлээн зөвшөөрчгүй байна. Зохиогчийн портал нь шугам чадал дээр байршуулахад туслаар аварий хангах; орон нутгийн арилжааны орд байдаг.

Идл цаг хугацаа, апсолут амьдралын болон төхөөрөмж мэдрэх нь өөр хэрэгцээг ашигладаг. Утас мэдрэмж чанарын байлгахгүй JIT. Зөвлөмж нь сервер дээр холбоотой сеанс дуусах. журналын үйл явц авах нь индивидуалны акаунт ашиглах.

JIT Энэ нь баталгаатай сеанс дээр хязгаарлагддаг. Эмэгтэйчүүдэд зориулагдсан аварий хангамж, нэг хэрэглэгчийн код болон шалтгаан хэрэгтэй. Энэ нь дэлхийн замсан байлгах биш юм. Портал 접근гүй байгаа бол местны орд нунтаг байх ёстой.

IP allowlist нь хүлээн зөвшөөрч байна IPv4, IPv6 Үнэгүй CIDR сүлжээний. Check Symfony довертой прокси конфигурацийн өмнө энэ ашиглаж байна. HTTPS Загвартай Cookies. Guardian Энэ вэб сервер болон мэдээллийн баз нь шинэчлэгддэггүй.

Өндөр, зах зээлийн хэмжээ нь одоогийн үйл явцад тодорхойлох болно. 5000 Загвар. Сайн дээр өөрчилж өмнө төрөл болон бүртгэл нь филт тэрэг. Газрын хэлбэртэй байна; их тээвэрлэх, хангах тохиргоо. Мест хасх чанарыг утасгүй хостел дээр эцсийн баталгаажуулагч биш юм.

Нэвтрэлт ба нууц үгийн хэсэгт хамгийн бага урт, шаардлагатай тэмдэгтийн төрлийг тохируулна. Шинэ нууц үгт үйлчилнэ; одоо байгаа бүртгэлүүдэд заавал шинэчлэх сонголтыг ашиглана. Guardian нь PHP дэмжвэл Argon2id, үгүй бол bcrypt ашиглана.

Бүх тогтмол үйл явц нь төрөл болон нийтлэл дээр филтрираж. Шинэ үйл явцад эхлээд, дэлгэрэнгүй хэлбэрээр 50. Scrolling дараагийн хуудас татаж авахгүй.

## Орчин


```dotenv
GUARDIAN_LOGIN_PATH=/internal/<random-48-hex>
GUARDIAN_ENCRYPTION_KEY=<64-hex>
GUARDIAN_STORAGE_DIR=<private-directory>
GUARDIAN_COLLECTION_BRIDGE=0
GUARDIAN_DEBUG_ERRORS_FOR_AUTHENTICATED=0
GUARDIAN_SHOW_PHP_VERSION=0
```


Прокси нь TLS, хэвийнжүүлэлт болон их урсгалын хамгаалалтыг хариуцна. Гарц нь оношилгоог чиглүүлэлтээс өмнө шалгана; бизнесийн зам бүртгэл эсвэл сесс уншихгүй. Guardian-ийн таних мэдээлэл Symfony-оос тусдаа. Хувийн хадгалалт ба түлхүүрийг хамт, нийтийн хавтаснаас гадуур нөөцөлнө. PHP эсвэл хост халдлагад өртвөл хоёулаа ил болж болно. Хадгалалт нэг хостод зориулагдсан. Эхлэлт, кэш, проксины алдаа бүх програмд нөлөөлж болно.

Хадгалалт ба түлхүүрийг хамт нөөцөлж сэргээхийг туршина. Алдсан түлхүүр автоматаар шинээр үүсэхгүй. Устгасны дараа профайлерыг зөвхөн хаалттай орчинд шалгана. Үйлдвэрлэл: APP_DEBUG=0, WebProfilerBundle ба цуглуулалт унтраалттай. Дотоод аудитын гинж халдлагад өртсөн хостын бүрэн бүтэн байдлыг нотлохгүй.

## Загварын болон хяналт

IP жагсаалтыг хоосолж, хуваарь, JIT болон алсын яаралтай хандалтыг унтраана. Нэвтрэлт, MFA, нийт түгжээ болон нэвтрэх түгжээ үлдэнэ. Сэргээсний дараа шаардлагатай хязгаарлалтыг самбарт дахин тохируулна.

on нь оношилгоог хааж бүх сессийг устгана; бизнесийн хуудас ажиллана. off нь зөвхөн нийт түгжээг тайлна: дахин нэвтрэх шаардлагатай, бусад бодлого хүчинтэй.


```bash
php bin/console guardian:policy:reset --env=dev
php bin/console guardian:lockdown on --env=dev
php bin/console guardian:doctor --env=dev
```
