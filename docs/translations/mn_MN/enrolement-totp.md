# Хоёр хүчин зүйлийн баталгаажуулалт

[Баримт бичгийн агуулга](README.md)


## Хоёр хүчин зүйлийн баталгаажуулалт

Бүх хүн нь өөрийн бүртгүүлэх болно TOTP тайлан, код баталгаажуулдаг.

Бүх хүн нь өөрийн бүртгүүлэх болно TOTP тайлан, код баталгаажуулдаг. MFA Блокс профилийн дор нь бүртгүүлэхгүй акаунт. Эдгээр захиалтай шаардлагагүй өмнө администрацийн арилжааны тогтмол байна. Гараар тохируулахыг сонгож түлхүүр оруулна уу. SHA-1, зургаан орон, 30 секундын мөчлөг ашиглана.

## 1. Хэн болохоо баталгаажуулах

Guardian-д нэвтрэхдээ ашигладаг нууц үгээ оруулна уу. Энэ тохиргоонд зөвхөн нэг удаа шаардана.

## 2. Түлхүүрийг баталгаажуулах аппд оруулна уу

Гараар тохируулахыг сонгож түлхүүр оруулна уу. SHA-1, зургаан орон, 30 секундын мөчлөг ашиглана.

## 3. Зургаан оронтой код баталгаажуулах

Апп дээрх кодыг оруулна уу. Хоёр дахь нууц үг шаардлагагүй.

## Нууцлал: вебсайтын URL-г бүү оруул

Апп нэр эсвэл сайт асуувал зөвхөн «ΩGuardian» эсвэл төвийг сахисан нэр оруул. Symfony суулгацын URL-г бүү оруул.

Нууц хадгал: энэ түлхүүрээр TOTP код үүсгэнэ. Бүү хуваалц, дэлгэцийн зураг бүү ав.

Түр нууц 10 минут эсвэл 5 буруу кодын дараа дуусна; дахин эхэлнэ. Алдаа гарвал маягт үлдэж нууц үгийг дахин асуухгүй. Баталгааны тоолуурыг дахин ашиглахын эсрэг хэрэглэнэ.

## Загварын болон хяналт

username-ийн TOTP нууц ба тоолуурыг арилгаж, сессүүдийг хүчингүй болгон бүртгэнэ. Шинэ баталгаажуулагч бүртгэнэ; нийт MFA шаардлага хэвээр тул профайлерыг хааж болно.


```bash
php bin/console guardian:mfa:reset admin --env=dev
```
