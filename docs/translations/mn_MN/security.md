# Аюулгүй байдлын бодлого

[Баримт бичгийн агуулга](README.md)

Эмзэг байдлыг bundle-sec@omegaguardian.fr рүү хувиар мэдэгдэж, шифрлэсэн суваг тохирно. Эхний мэдээнд нууц, идэвхтэй токен, хувийн URL бүү оруул. Guardian, Symfony, PHP хувилбар, нөлөө, урьдчилсан нөхцөл, хамгийн бага давтах алхмыг өгнө. Хариуцагч хүлээн авч, шалгаж, хувиар засаж, туршин, мэдэгдэл ба засварыг уялдуулна.

Нууц үг, TOTP нууц, шифрлэлтийн түлхүүр болон оношилгооны URL-ийг имэйлээр хэзээ ч бүү илгээ.

Хадгалалт ба түлхүүрийг хамт нөөцөлж сэргээхийг туршина. Алдсан түлхүүр автоматаар шинээр үүсэхгүй. Устгасны дараа профайлерыг зөвхөн хаалттай орчинд шалгана. Үйлдвэрлэл: APP_DEBUG=0, WebProfilerBundle ба цуглуулалт унтраалттай. Дотоод аудитын гинж халдлагад өртсөн хостын бүрэн бүтэн байдлыг нотлохгүй.
