# Орчуулгууд

[Баримт бичгийн агуулга](README.md)

Портал нь 28 бүсийн сонголт, 25 орчуулгын сантай; дөрвөн англи хувилбар нэг сан ашигладаг. Тогтмол текстийг орчуулж аюулгүй дүрслэнэ. Хэрэглэгчийн нэр, өөрийн мэдэгдэл, өгөгдлийг орчуулахгүй. Алсын үйлчилгээнд текст илгээхгүй. Аудит түлхүүр, параметр, UTF-8, тушаал, холбоос шалгана; HTTP туршилт бүх бүсийн хуудсыг үзнэ.
