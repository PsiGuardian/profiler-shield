# Хувь нэмэр

[Баримт бичгийн агуулга](README.md)

Тусгаарласан Symfony туршилтын програмд ажиллана. Бизнесийн хүртээмж, зөвшөөрөлгүй оношилгооны татгалзлыг хадгална. Холбогдох хувилбарт нэргүй хүсэлт, цуцалсан сесс, хуваарь, хадгалалтын алдааг туршина. Тогтвортой түлхүүр, аюулгүй дүрслэл, бүтэн орчуулга ашиглана. Туршилт, зураг, Git-д нууцгүй; заавал сүлжээ шаардахгүй. Нөлөө ба шалгалтаа тайлбарлана.
```bash
composer install
composer test
php tests/translation_audit.php --strict
php tests/documentation_audit.php
node tests/password_model.js
vendor/bin/phpunit -c phpunit.xml.dist
```
