# Kontribusi

[Daftar isi dokumentasi](README.md)

Bekerja di aplikasi uji Symfony terisolasi. Pertahankan ketersediaan bisnis dan penolakan diagnostik tanpa izin. Uji permintaan anonim, sesi dicabut, jadwal dan kegagalan penyimpanan pada versi terkait. Gunakan kunci stabil, escape dan terjemahan lengkap. Tanpa rahasia di tes, gambar atau Git; tanpa ketergantungan jaringan wajib. Jelaskan dampak dan validasi.
```bash
composer install
composer test
php tests/translation_audit.php --strict
php tests/documentation_audit.php
node tests/password_model.js
vendor/bin/phpunit -c phpunit.xml.dist
```
